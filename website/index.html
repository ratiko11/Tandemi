Ask on GitHub

Does Tandemi change my main branch?

No. It merges in its own copy. You save the result as a new branch or a .zip and merge it yourself.

Do I need an API key for the AI fixes?

No. Tandemi uses Claude Code with your Claude plan. An Anthropic API key works too.

Where does Tandemi keep my code?

It stays on your computer. Only an AI fix sends the bug and its file to Claude, and the pull request check talks to GitHub.

Can my team use Tandemi together?

Yes. Make a team, invite people with a link and give each a role. Teammates on the same network open it in their browser.

Does Tandemi work with GitLab?

Merging works with any git project. The pull request comments work with GitHub for now.
